# Publicação no GitHub e referências

## O que publicar

Esta pasta contém documentação e imagens prontas para revisão pública. Não contém aplicativo executável, dados reais de clientes, credenciais, áudios de entrevista, consentimentos ou evidências fabricadas. O título técnico do repositório sugerido é padaria-jose-mvp; confirmar o título acadêmico separadamente.

## Pela interface do GitHub

1. Entrar na própria conta em github.com e criar um repositório chamado padaria-jose-mvp.
2. Selecionar Public, conforme a preferência informada pelo autor.
3. Revisar os arquivos desta pasta. Não incluir o ZIP dentro do repositório nem a pasta .git.
4. Usar Add file → Upload files e enviar o conteúdo mantendo docs/, prototipos/ e validacao/.
5. Conferir README, imagens, links e exclusão de dados pessoais antes de confirmar o envio.

Se enviar pelo terminal, o Git já foi preparado localmente. Adicionar o endereço HTTPS/SSH exato fornecido pelo GitHub e fazer push da branch main com a própria autenticação. Não colocar token ou senha em URL, arquivo ou comando compartilhado.

Publicar estes documentos não publica uma aplicação nem autoriza contratar hospedagem. Não publicar registros futuros de validação sem autorização e anonimização adequadas.
